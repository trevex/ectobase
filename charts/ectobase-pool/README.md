## ectobase-pool

This chart deploys the ectobase compute-cluster ("pool") stack: the `flowplane` eBPF or DPDK dataplane DaemonSet, the `netplane-agent` DaemonSet (overlay route control), the `hub-broker` Deployment (syncs compiled objects from the hub), the `flowplane-cni` installer DaemonSet (drops the CNI binary onto nodes), the `pod-materializer` Deployment (turns CompiledContainer into Pods), the optional `vm-materializer` Deployment (turns CompiledVM/CompiledVolumeAttachment into KubeVirt VMs), the KubeVirt network-binding NAD, optional tier-1 autonomous failover (medik8s NHC + SNR), and all required CRDs and RBAC — RBAC rules are sourced from the generated `files/<role>/role.yaml` files so they stay in sync with the controller-gen markers in code.
